## 常见 HTTP 状态码

| 状态码 | 含义 | 处理建议 |
|---|---|---|
| 401 | API Key 无效或未提供 | 检查请求头中的 Authorization 是否正确携带令牌 |
| 429 | 请求频率过高或余额不足 | 降低请求频率，或前往后台检查账户余额 |
| 500 | 上游模型服务异常 | 稍后重试，或切换其他可用模型 |
| 502 / 503 | 网关或上游服务暂时不可用 | 稍后重试，若持续出现请联系客服 |

## 常见问题排查

- **提示模型不存在**：请前往模型价格页确认模型名称拼写是否正确，部分模型需要完整版本号。
- **响应内容被截断**：检查请求参数中的 `max_tokens` 设置是否过小。
- **连接超时**：确认 BASE_URL 是否填写正确，部分客户端需要额外添加 `/v1` 后缀。
